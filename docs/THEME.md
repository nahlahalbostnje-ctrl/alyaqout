# ثيم الواجهة — منصة الياقوت

> تاريخ: 2026-08-09  
> الملف التقني: `codes/frontend/src/theme/palette.ts`  
> CSS: `codes/frontend/src/index.css` (`:root` tokens)

## المراحل

| مرحلة | النطاق | الحالة |
|--------|--------|--------|
| 1 | توكنز موحّدة + CSS | ✅ مكتمل |
| 2 | Layouts + Login + Landing | ✅ مكتمل |
| 3 | بوابات الطالب وولي الأمر | ✅ مكتمل (استيراد الثيم + قوائم فاتحة) |
| 4 | معلم / مشرف / أدمن | ✅ مكتمل |
| 5 | توثيق | ✅ هذا الملف |

## النسبة

| النسبة | اللون | Hex |
|--------|--------|-----|
| ~70% | خلفية/أبيض | `#F7F9FA` / `#FFFFFF` |
| ~20% | أزرق هادئ | `#3B82A0` |
| ~7% | نص كحلي | `#243746` |
| ~3% | ذهب الهوية | `#C59341` |

## قواعد الاستخدام

- **الذهبي** (`brand.gold`): شعار ونقاط هوية نادرة فقط — ليس خلفية الصفحات ولا كل الأزرار.
- **الأساسي التفاعلي**: `#3B82A0` — في الكود كثير من المفاتيح القديمة اسمها `gold` / `goldGrad` لكنها تشير للأزرق الهادئ للتوافق مع الصفحات.
- **المساعد**: `#78B7C9`
- **النجاح**: `#6FAF8A`

## الاستيراد

```ts
import { C, brand } from '../theme/palette';
// C.primary / C.gold  → أزرق تفاعلي
// brand.gold          → ذهب الياقوت الحقيقي
```

`SuperAdminShell` يعيد تصدير `C` حتى تستمر صفحات السوبر أدمن التي تستورد منه بالعمل دون تعديل كل ملف.

## ما تغيّر في الهيكل

- قوائم جانبية **فاتحة** لكل الأدوار (طالب، ولي أمر، معلم، مشرف، أدمن، سوبر أدمن).
- العنصر النشط: خلفية زرقاء شفافة + حد يمين بلون `primary`.
- تسجيل الدخول: خلفية/أزرار بالأزرق الهادئ بدل الذهب القوي.
- الصفحة الرئيسية: شريط أزرق هادئ فوق الهيرو + هيدر فاتح بعد التمرير.
