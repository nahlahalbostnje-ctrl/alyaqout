## خصوصية أدمن المنطقة vs السوبر أدمن

| البند | أدمن المنطقة | السوبر أدمن |
|--------|---------------|-------------|
| طالب: الاسم + المواد المسجّلة | ✅ يظهر | ✅ |
| طالب: هاتف / إيميل / عنوان | ❌ محجوب من API والواجهة | ✅ كامل + بحث/تصدير |
| إنشاء طالب من `/admin/users` | ❌ ممنوع — عبر `/register` فقط | ✅ عبر لوحة السوبر |
| مالية (اشتراكات/مشتريات) | ✅ تظهر **بدون** هاتف الطالب | ✅ مع الهاتف |
| معلم / ولي أمر / مشرف (تواصل) | ✅ كما كان | ✅ |
